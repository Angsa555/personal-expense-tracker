Personal Expense Tracker

A simple Python command-line application for tracking personal expenses with local JSON storage.

Features

- Add new expenses
- Store expense data locally in JSON format
- View expense history
- Calculate total expenses
- Record date, category, amount, and notes
- Lightweight and easy to run

Requirements

- Python 3.8 or newer
- No external dependencies required

Usage

Clone the repository and run:

python expense_tracker.py

Choose an option from the menu:

1. Add expense
2. Show expenses
3. Exit

Data Format

Each expense contains:

- Date
- Category
- Amount
- Note

Expense data is stored locally in "expenses.json".

Project Structure

personal-expense-tracker/
├── expense_tracker.py
├── README.md

Purpose

This project is a small Python application created to practice file handling, JSON data storage, user input, and basic application structure.
